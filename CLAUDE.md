# HumanHD agent notes

- Build: `swift build`; tests: `swift test`; visual check: `swift run -q humanhd look ...` then Read the PNG.
- Conventions: meters, +Y up, character faces +Z, character's left is +X, feet at y = 0.

- Anatomy: describe left-side rotations; `Anatomy` mirrors to the right. hm08 rests with elbows bent ~41 degrees.
